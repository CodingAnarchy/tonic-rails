# tonic-rails example app

A minimal Rails app serving `demo.v1.ItemService` (see `protos/items.proto`)
with unary, server-streaming and client-streaming RPCs.

```sh
cd example
bundle install
bin/rails tonic_rails:routes     # list registered gRPC methods
bin/rails tonic_rails:serve      # serve on 127.0.0.1:50052
```

Then, with [grpcurl](https://github.com/fullstorydev/grpcurl) (reflection is
enabled outside production):

```sh
grpcurl -plaintext -d '{"id": 1}' 127.0.0.1:50052 demo.v1.ItemService/GetItem
grpcurl -plaintext -d '{"name": "New", "tags": ["featured"]}' 127.0.0.1:50052 demo.v1.ItemService/CreateItem
grpcurl -plaintext -d '{"tag": "featured"}' 127.0.0.1:50052 demo.v1.ItemService/ListItems
grpcurl -plaintext -d '{"name": "a"} {"name": "b"}' 127.0.0.1:50052 demo.v1.ItemService/ImportItems
```

Layout:

| Path | Purpose |
|------|---------|
| `protos/items.proto` | Service definition |
| `lib/grpc/items_pb.rb` | Generated by `PROTO_DIR=protos RUBY_OUT=lib/grpc bin/rails tonic_rails:compile_protos` |
| `app/grpc/item_service.rb` | Handler (autoloaded) |
| `app/models/item_store.rb` | In-memory stand-in for a model |
| `config/initializers/tonic_rails.rb` | Registers the handler in `to_prepare` |
| `config/application.rb` | `config.tonic_rails.*` settings |
